## ⚙️ Engineering & Architecture

- **100% Pure Semantic HTML5 & CSS3**: Zero JavaScript. All micro-interactions, modal dialogs, tab switching, and navigation run natively via CSS (`:target`, `:checked` sibling selectors, `:hover`, `:focus-visible`).
- **Daylight Lookbook**: High-impact horizontal side-wise scrollable showcase with CSS scroll snap (`scroll-snap-type: x mandatory`), bespoke champagne-gold scrollbars, and pure CSS quick-jump anchor navigation.
- **Interactive Telemetry Matrix**: Comparative technical specifications across power, weight, aerodynamics, and transmission.
- **Client Allocation Dossier**: Modal and inquiry form for private collectors.
- **Responsive & Accessible**: Fluid typography (`clamp()`), semantic tags, ARIA attributes, and responsive mobile adaptations.

## 🚀 Running Locally

You can preview the atelier locally using any static web server:

```bash
# Python 3
python3 -m http.server 8080

# Or with Node
npx serve
```

Then navigate to `http://localhost:8080` in your web browser.
